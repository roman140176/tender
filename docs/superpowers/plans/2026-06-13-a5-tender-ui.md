# A5: UI закупок (кабинет менеджера) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Менеджер работает с закупками в кабинете: список с фильтрами (13.2), карточка с объяснимым баллом/рисками/рекомендацией (13.3), статусы (13.4), комментарии, история, ответственный; просмотр логов запусков.

**Architecture:** Inertia 2 + Vue 3 (`<script setup>`, без TS) поверх существующего конвейера скоринга A4. В HTTP-контексте `TenantContext` поднят middleware ВЫШЕ route-binding → `CompanyTender::query()` и неявная привязка моделей авто-скоупятся по компании (изоляция бесплатно, в отличие от джоб A4). Список строится запросом по `company_tenders` (per-company проекция) + join `tenders` + агрегаты лучшего матча; серверные фильтры (13.2) и пагинация. Карточка — `company_tender` + его `tender_matches` (объяснение через `MatchReasonPresenter`, доступ к jsonb-ключам по имени). Мутации (статус/комментарий/ответственный) — под новым гейтом `manage-tender-workflow` (admin+manager); просмотр — `view-tenders` (любой пользователь компании).

**Tech Stack:** Laravel 13, Inertia 2, Vue 3 (`<script setup>`), Tailwind + `@tailwindcss/forms`, Pest 4 (+ `Inertia\Testing\AssertableInertia`), PHPStan L6, Pint. PostgreSQL 16.

## Зафиксированные проектные решения

1. **Два гейта вместо ролей в коде.** `view-tenders` = `company_id !== null` (любой пользователь компании, вкл. viewer; superadmin без компании → false). `manage-tender-workflow` = `company_id !== null && role ∈ {Admin, Manager}` (статусы/комментарии/ответственный — §11). Шарятся в Inertia → UI скрывает мутации у viewer. Бэкенд — авторитетная проверка (Request/контроллер), фронт — только UX.
2. **HTTP-изоляция бесплатна.** `TenantContext` установлен middleware (выше route-binding). Поэтому контроллеры используют `CompanyTender::query()` / route-binding без `withoutTenancy()` — scope сам режет по компании; чужой id → 404. (Это противоположно джобам A4, где контекста нет.)
3. **Карточка маршрутизируется по `CompanyTender`** (per-company проекция — то, с чем работает менеджер), route-param `companyTender`. Глобальная `tenders` напрямую не отдаётся (§11). Привязка скоупится → чужая проекция = 404.
4. **Лучший матч для отображения.** В списке релевантность = `company_tenders.best_level/best_score`. В карточке объяснение берём из `tender_match` с максимальным `score` среди матчей пары (если несколько профилей сматчили) — он соответствует `best_score`. Показываем также, по каким направлениям закупка прошла.
5. **`MatchReasonPresenter`** (§5 «строка рендерится презентером»): преобразует `reason: [{rule,points,detail}]` в список рус. строк, обращаясь к ключам **по имени** (устойчиво к jsonb-переупорядочиванию, follow-up #3). Переиспользуется картой A5 и Telegram A7. Риск-флаги → рус. строки тем же классом.
6. **Скрытие осиротевших проекций** (follow-up #2): список по умолчанию показывает `company_tenders`, у которых есть ≥1 `tender_match` (исключённые по негативу проекции без матчей не шумят). Реализуется `whereHas('matches')` (в HTTP scope активен). Проекции с реальным матчем score=0 НЕ скрываются (у них есть строка матча).
7. **Статусы — свободный переход.** ТЗ 13.4 даёт 12 статусов без жёсткого графа переходов → менеджер может установить любой из 12; каждая смена пишет `tender_status_history` (old/new/user). Нет «машины состояний» (YAGNI для A5).
8. **Нормализация ключа — только пробелы** (follow-up #1): `Keyword::normalizeValue` делает trim + NBSP→пробел + схлопывание кратных пробелов, **без** смены регистра/ё (регистр/ё уже обрабатываются симметрично в CandidateQuery и резолвере; рассинхрон был только по пробелам). Применяется в `KeywordController::store` ДО валидации (чтобы `unique` ловил коллизии нормализованных значений). Отображение ключа (регистр) не меняется.
9. **Логи запусков**: `RadarRun` авто-скоупится (BelongsToCompany); `SourceCollectRun` НЕ имеет scope → фильтруем `where('company_id', ...)` явно (показываем только ручные импорты этой компании). Просмотр — `view-tenders`.

- [ ] **Step 3: Реализовать normalizeValue**

```php
    /** Схлопывание пробелов/NBSP + trim. Регистр и ё НЕ трогаем (обрабатываются симметрично в матчере). */
    public static function normalizeValue(string $value): string
    {
        $value = str_replace("\u{00A0}", ' ', $value);

        return trim((string) preg_replace('/\s+/u', ' ', $value));
    }
```

```php
namespace App\Scoring;

final class MatchReasonPresenter
{
    /** rule => шаблон. {detail} подставляется, знак балла добавляется отдельно. */
    private const RULE_LABELS = [
        'exact_in_title' => 'Точная фраза в названии: «{detail}»',
        'exact_in_description' => 'Точная фраза в описании: «{detail}»',
        'keyword_in_title' => 'Ключ в названии: «{detail}»',
        'keyword_in_description' => 'Ключ в описании: «{detail}»',
        'high_priority_bonus' => 'Высокоприоритетный ключ: «{detail}»',
        'low_priority_score' => 'Низкоприоритетный ключ: «{detail}»',
        'negative_keyword' => 'Минус-слово: «{detail}»',
        'price_above_min' => 'Цена не ниже минимума: {detail}',
        'price_below_min' => 'Цена ниже минимума: {detail}',
        'priority_region' => 'Приоритетный регион: {detail}',
        'deadline_far_bonus' => 'Достаточный срок до дедлайна: {detail}',
        'deadline_soon_penalty' => 'Слишком близкий дедлайн: {detail}',
        'okpd_match' => 'Совпадение по ОКПД2/КТРУ: {detail}',
        'source_closed' => 'Закупка закрыта/отменена',
    ];

    private const RISK_LABELS = [
        'deadline_soon' => 'Скоро дедлайн',
        'no_price' => 'Цена не указана',
        'no_deadline' => 'Дедлайн не указан',
        'source_closed' => 'Источник закрыт',
    ];

    /**
     * @param list<array{rule?: string, points?: int, detail?: string}> $reason
     * @return list<string>
     */
    public static function lines(array $reason): array
    {
        $out = [];
        foreach ($reason as $entry) {
            $rule = (string) ($entry['rule'] ?? '');
            $points = (int) ($entry['points'] ?? 0);
            $detail = (string) ($entry['detail'] ?? '');

            $template = self::RULE_LABELS[$rule] ?? "{$rule}: {detail}";
            $text = str_replace('{detail}', $detail, $template);

            $out[] = $text.' ('.self::sign($points).')';
        }

        return $out;
    }

    /**
     * @param list<string> $flags
     * @return list<string>
     */
    public static function risks(array $flags): array
    {
        return array_values(array_map(
            fn (string $flag): string => self::RISK_LABELS[$flag] ?? $flag,
            $flags,
        ));
    }

    private static function sign(int $points): string
    {
        return $points < 0 ? '−'.abs($points) : '+'.$points;
    }
}
```

```php
<?php

namespace App\Tenders;

use App\Models\CompanyTender;
use Illuminate\Contracts\Pagination\LengthAwarePaginator;
use Illuminate\Database\Eloquent\Builder;

final class TenderListQuery
{
    /**
     * Список закупок компании (per-company проекция) с фильтрами 13.2 ТЗ.
     * Полагается на активный TenantContext (HTTP) — company_tenders скоупится по компании.
     * Скрывает осиротевшие проекции без единого tender_match (follow-up A4 #2).
     *
     * @param array<string, mixed> $filters
     * @return LengthAwarePaginator<CompanyTender>
     */
    public function paginate(array $filters, int $perPage = 25): LengthAwarePaginator
    {
        $query = CompanyTender::query()
            ->with(['tender.source', 'assignee:id,name'])
            ->whereHas('matches') // только реально сматченные (не осиротевшие)
            ->when($this->filled($filters, 'status'), fn (Builder $q) => $q->where('status', $filters['status']))
            ->when($this->filled($filters, 'level'), fn (Builder $q) => $q->where('best_level', $filters['level']))
            ->when($this->filled($filters, 'assignee'), fn (Builder $q) => $q->where('assigned_user_id', (int) $filters['assignee']))
            ->when($this->filled($filters, 'profile_id'), fn (Builder $q) => $q->whereHas(
                'matches',
                fn (Builder $m) => $m->where('search_profile_id', (int) $filters['profile_id']),
            ))
            ->whereHas('tender', function (Builder $t) use ($filters): void {
                $t->when($this->filled($filters, 'source_id'), fn (Builder $q) => $q->where('source_id', (int) $filters['source_id']))
                    ->when($this->filled($filters, 'law_type'), fn (Builder $q) => $q->where('law_type', $filters['law_type']))
                    ->when($this->filled($filters, 'region'), fn (Builder $q) => $q->where('region', $filters['region']))
                    ->when($this->filled($filters, 'customer'), fn (Builder $q) => $q->where('customer_name', 'ILIKE', '%'.$this->escape((string) $filters['customer']).'%'))
                    ->when($this->filled($filters, 'price_min'), fn (Builder $q) => $q->whereNotNull('price')->where('price', '>=', $filters['price_min']))
                    ->when($this->filled($filters, 'price_max'), fn (Builder $q) => $q->whereNotNull('price')->where('price', '<=', $filters['price_max']))
                    ->when($this->filled($filters, 'published_from'), fn (Builder $q) => $q->where('published_at', '>=', $filters['published_from']))
                    ->when($this->filled($filters, 'deadline_to'), fn (Builder $q) => $q->where('deadline_at', '<=', $filters['deadline_to']))
                    ->when($this->filled($filters, 'q'), function (Builder $q) use ($filters): void {
                        $like = '%'.$this->escape((string) $filters['q']).'%';
                        $q->where(fn (Builder $w) => $w->where('title', 'ILIKE', $like)->orWhere('description', 'ILIKE', $like));
                    });
            })
            ->orderByDesc('best_score')
            ->orderByDesc('first_matched_at');

        return $query->paginate($perPage)->withQueryString();
    }

    /** @param array<string, mixed> $filters */
    private function filled(array $filters, string $key): bool
    {
        return isset($filters[$key]) && $filters[$key] !== '' && $filters[$key] !== null;
    }

    private function escape(string $value): string
    {
        return str_replace(['\\', '%', '_'], ['\\\\', '\\%', '\\_'], $value);
    }
}
```
